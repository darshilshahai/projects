# Northwind Labs — Security Guidelines

## Passwords

All employees must use a password of at least twelve characters that includes a mix of letters, numbers, and symbols. Passwords must be changed every ninety days, and the same password cannot be reused within a twelve-month period. Sharing passwords with anyone, including colleagues, is strictly forbidden.

## Two-factor authentication

Two-factor authentication is mandatory for all company accounts, including email, code repositories, and the finance portal. Employees should use the approved authenticator app rather than SMS codes wherever possible, because SMS codes are less secure.

## VPN

When working remotely, employees must connect to the company network through the official VPN before accessing any internal systems. Public Wi-Fi in cafes or airports must never be used to access internal systems without the VPN switched on.

## Device security

Company laptops must have full-disk encryption enabled and the screen must lock automatically after five minutes of inactivity. Lost or stolen devices must be reported to the IT security team within twenty-four hours so that access can be revoked remotely.

## Handling customer data

Customer data must never be copied to personal devices, personal email, or personal cloud storage. Any suspected data breach must be reported immediately to the security team, who will follow the formal incident response process.
